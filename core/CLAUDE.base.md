# Project operating rules (harness core)

- Read `.claude/rules/collaboration.md` and follow it: options -> decision -> draft -> approval.
- Start multi-domain work with the `lead` agent. Specialists live in `.claude/agents/`; skills in `.claude/skills/`.
- Keep `docs/STATE.md` current (goal, decisions, open questions, next step) — it is read at every session start.
- UI/copy work must satisfy `.claude/rules/anti-slop.md`.
- Never fabricate numbers. Never ship, publish, send or spend without an explicit yes.
- Tests/lint must be run and reported honestly before declaring done.
