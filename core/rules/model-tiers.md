# Model tiers for agents
Adapted from Claude-Code-Game-Studios `model-tiers.md` (MIT). Agent `model:` is applied; skill `model:` only when typed as /skill.

| Tier | model | Use for |
|---|---|---|
| Director | opus | architecture, scope, strategy, security, final review |
| Specialist | sonnet | implementation, writing, analysis, research |
| Lookup | haiku | read-only status, formatting, simple lookups |

Rule: spend opus on decisions that are expensive to reverse; spend sonnet on volume.
