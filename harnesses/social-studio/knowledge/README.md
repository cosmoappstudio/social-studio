# knowledge/
Sosyal medya ekibinin içerik ürettiği bilgi tabanı. `install.sh` bunu hedef projede `docs/knowledge/` altına koyar.
- `orphex-product.md` — PDF'lerden derlenmiş ürün bilgisi (iddiaların kaynağı).
- `sources/` — orijinal PDF'ler (rehberler). Güncellendikçe değiştir ve `orphex-product.md`'yi yenile (`/knowledge-refresh`).
Yeni bilgi (blog, release notes, SSS, müşteri hikayesi) eklemek için `docs/knowledge/` altına `.md` olarak koy; ajanlar bu klasörü tarar. İddia kuralı: postta yazan her rakam/özellik buradaki bir dosyada geçmeli.
