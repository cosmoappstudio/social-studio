Ask only what is missing, fill the rest from the repo/conversation. Write `docs/brand.md`: product name + one-line pitch; 6 colour tokens (ind/ink/paper/accent/lav/mint) copied into `docs/templates/brand.css`; fonts; **canonical numbers** (e.g. '65+ sources'); launch date/time/timezone (mark UNCONFIRMED if guessed); platforms and sizes; banned items (mascots, upvote asks, claims). Why: every later contradiction (60 vs 65+, wrong date) came from this file not existing.
